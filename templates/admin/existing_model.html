Algorithm Overview

The existing model uses TF-IDF (Term Frequency-Inverse Document Frequency) vectorization followed by cosine similarity scoring. It retrieves the top-K most similar passages to the user's query based on word overlap and frequency.

Characteristics
  • Keyword-based retrieval
  • Fast response time (~0.1s)
  • No semantic understanding
  • No evidence verification
  • Lower precision on complex queries
