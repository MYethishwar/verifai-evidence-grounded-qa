How this is measured

Questions. The curated test set (20 questions labelled with their source article) and every sample question in the knowledge base (labelled with its topic).

Correct source. A returned passage counts as correct when it belongs to a labelled source for that question. Each question is scored on its top 10 results.

Same conditions. Both engines search the same {{ b.index_passages }} passages with the same topic filter. Only the ranking method differs: TF-IDF cosine similarity versus BM25.

Scope guard. Every benchmark question must be accepted as medical; {{ b.scope_guard.out_scope_total }} everyday questions (sport, finance, travel…) must be declined.

Reading these results. VerifAI's search finds the correct source as often as the baseline and is several times faster. On ranking the correct source first, the two are within a few questions of each other. VerifAI's main advantage is downstream: it writes an answer from the top passages, cites them, and verifies the answer against them. Every individual answer shows those measurements in its answer report.
